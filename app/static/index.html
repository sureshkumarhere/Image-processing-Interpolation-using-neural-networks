About Super-Resolution Evaluation Metrics

PSNR (Peak Signal-to-Noise Ratio)

Measures signal power relative to reconstruction noise. Higher values (in dB) indicate smaller pixel differences. Evaluated on the 8-bit quantized ITU-R BT.601 Y-luminance channel with border cropping.

SSIM (Structural Similarity Index)

Evaluates structural similarity, luminance, and contrast preservation between SR and ground truth. Values range from 0.0 to 1.0 (higher is better).

LPIPS (Learned Perceptual Image Patch Similarity)

Measures deep feature distance using AlexNet embeddings. Lower values indicate better perceptual human alignment.

Note on Objective Metrics

PSNR and SSIM require an exact pixel-aligned High-Resolution ground-truth reference image. Higher scores reflect fidelity to the reference image but do not guarantee higher sharpness or subjective aesthetics.
